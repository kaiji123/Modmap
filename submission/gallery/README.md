# ModMap screenshot gallery

These screenshots come from the running app in **Simulation** mode. Names, chat messages, and moderation results are simulated; no Twitch moderation request was made for these images.

- `01-network-map.png` — directed conversation map with overlapping targets.
- `02-chatter-context.png` — selected chatter and message context.
- `03-review-and-support.png` — selection review with simulated subscription/gift context.
- `04-simulated-action-results.png` — local bulk action with per-user results.
- `05-autoban-controls.png` — autoban settings.

Open `index.html` to browse the gallery. Screenshots are 1920×1080 PNGs suitable for the Devpost project gallery.
